# TP2 - Lenguaje IV

Sitio en React (Vite) con 3 páginas: Inicio, Servicios y Contacto.

## Uso local

```
npm install
npm run dev
```

## Publicar en GitHub Pages

```
npm run deploy
```

Esto genera el build y lo sube a la rama `gh-pages` del repositorio. Después, en GitHub, andá a Settings > Pages y elegí la rama `gh-pages` como fuente.
